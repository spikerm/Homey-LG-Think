0.7.4
- Smart Washing now learns the real total duration LG reports after a program starts.
- Stores one learned duration per wash cycle and keeps the last 5 cycles per program.
- Uses the rolling average as the next expected program duration for Homey Energy planning.
- Updates the current cycle sample when LG adjusts the total time after load sensing, without counting duplicate measurements.
- Falls back to the existing model estimates until a real duration has been learned.

- Improved Smart Washing startup so widgets share cached ThinQ2 data and avoid unnecessary duplicate LG requests.
- Kept active-cycle guards for Wake and Start commands.
